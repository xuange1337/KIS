# Шрифты для выгрузки в PDF

`pdfmake` поставляется со шрифтом Roboto без кириллицы, поэтому русский текст
в отчётах выводится с DejaVu Sans (свободная лицензия DejaVu, производная от
Bitstream Vera). Файлы подключаются в `export.service.ts` как встроенные шрифты
`pdfmake` и попадают в образ на этапе сборки (см. `server/Dockerfile`).
