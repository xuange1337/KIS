# Проверка метрик и индексов поиска, 25.10.2026

Дополнение к протоколу от 08.10.2026: после него в прототип добавлены
эндпоинт метрик и триграммные индексы поиска. Здесь зафиксировано только то,
что запускалось в этот день; браузерные сценарии, нагрузка и восстановление
копии не перезапускались, их результаты остаются в прежнем протоколе.

## Что добавлено

- `/api/metrics` — выдача в формате Prometheus: счётчики запросов по шаблону
  маршрута, гистограмма длительности, счётчики писем и фоновых заданий,
  состояние базы, организации по статусам, очередь выгрузок. Маршрут закрыт
  общим секретом `METRICS_TOKEN`: без него его нет (404), с неверным — 401.
- Миграция `AddTrigramSearchIndexes` — индексы для подстрочного поиска
  клиентов.
- Снимок схемы в тесте миграций теперь включает индексы, поэтому миграция,
  меняющая только индексы, проверяется на обратимость.

## Условия

Локальная машина, PostgreSQL в контейнере, отдельная база `crm_test`,
пересоздаваемая перед прогоном; тесты запускались последовательно.

## Результаты

| Проверка | Итог |
|---|---|
| API e2e | 291/291, 26 наборов (в т. ч. новые `metrics`, `search-indexes`) |
| Web unit/component | 71/71, 13 наборов |
| Prettier (server) | замечаний нет |
| ESLint | 0 ошибок, 15 предупреждений |

Новый набор `metrics.e2e-spec.ts` проверяет: отсутствие маршрута без секрета,
401 без заголовка и с неверным токеном, отказ для обычного токена
пользователя, формат выдачи, учёт маршрута по шаблону (`/api/clients/:id`,
а не фактический адрес) и исключение самих метрик из статистики.
Набор `search-indexes` проверяет по плану запроса, что на таблице в 40 000
строк подстрочный поиск использует триграммный индекс, а не
последовательное чтение.

## Ограничения

- План запроса подтверждает выбор индекса, но не измеряет выигрыш в секундах:
  время зависит от машины, и на синтетических данных оно не переносится на
  реальные.
- Число тестов выросло с 242 до 291 (API) и с 58 до 71 (web) с момента
  протокола от 08.10; прежние цифры в протоколах той даты исторически верны и
  не изменялись.
- Метрики проверены тестами, но не подключены к реальному Prometheus и
  дашборду.
