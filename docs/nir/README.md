## Проверенные результаты

Полный повторный прогон 25.10.2026 ([протокол](experiments/2026-10-25-metrics-and-search-indexes.md)):

- CI целиком: 291/291 API e2e и 71/71 web; lint — 0 ошибок, 15 предупреждений (26.10.2026 доведён до 0 предупреждений). Прогон выявил три дефекта (лицензия MIT-0, ложное срабатывание проверки секретов, жёсткий путь в скрипте копии); они исправлены.
- Браузер: 30/30 во втором полном прогоне; в первом 29/30 из-за нестабильного сценария.
- Нагрузка: 6 150 запросов, ошибок нет; p95 при 30 workers — 56,51–57,16 мс (08.10 было 47,91–51,59 мс; причина разницы не установлена).
- Копия синтетической базы: восстановлены и сравнены 19 таблиц и контрольный файл (проверка повторена 26.10.2026 после исправления списка таблиц в скрипте).
- Предыдущий полный прогон 08.10.2026: 242/242 API и 58/58 web ([протокол](experiments/2026-10-08-research-validation.md)).

Полные условия и ограничения находятся в протоколе. Нагрузочное измерение не доказывает предельную мощность сервера; время и ошибки реальных менеджеров, экономический эффект не измерялись. Статья готова для содержательной проверки; перед внешней подачей нужны требования выбранного издания и доступные читателю дополнительные материалы.

## Связь с программным проектом

Исследование опирается на действующий прототип KIS CRM. Проверяемые проектные решения: модульная веб-архитектура, единая модель клиентских данных, ролевая и межорганизационная изоляция, управление сделками и активностями, аудит действий, отчётность, резервное копирование и контейнерное развёртывание.
