# Задание на практику

`zadanie-23fiit-b.docx` — индивидуальные задания на учебную практику
(НИР) группы 23ФИИТ(б), ОГУ, выданы 01.10.2026. Файл содержит задания
всех десяти обучающихся; к этому репозиторию относится задание
Орлова Г.Н.

## Задание Орлова Г.Н.

Вид практики: учебная практика, научно-исследовательская работа.
Срок: 01.09.2026 — 27.12.2026. Руководитель: Н.Н. Симченко.

| Этап | Что требуется | Срок сдачи |
|---|---|---|
| 1 | Обосновать актуальность темы. Определить цель и задачи исследования | 15.10.2026 |
| 2 | Обзор и анализ научных трудов в области разработки АРМ, не менее пяти отечественных и зарубежных источников. В выводе обосновать выбор источников | 02.11.2026 |
| 3 | Анализ существующих аналогов приложения, сравнительная характеристика с достоинствами и недостатками. В выводе — анализ результатов | 16.11.2026 |
| 4 | Обосновать выбор инструментальных и вычислительных средств разработки | 23.11.2026 |
| 5 | Структура приложения: подсистемы, узлы, связи. Описание компонентов и их взаимодействия. Модель приложения. В выводе — анализ результатов | 07.12.2026 |
| 6 | Научная публикация по результатам НИР | 21.12.2026 |
